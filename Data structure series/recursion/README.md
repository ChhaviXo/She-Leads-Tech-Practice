# Recursion

Work through each level in order. Starter filenames are numbered from 1 within each level to match its problem set.

1. [Level 1: fundamentals](./level1/Problems.md) — factorial, array products, range sums, and Fibonacci.
2. [Level 2: powers](./level2/Problems.md) — power, Power of Two, and Power of Three.
3. [Level 3: strings and arrays](./level3/Problems.md) — reverse, palindrome, recursive predicates, and flatten.
4. [Level 4: nested objects and transformations](./level4/Problems.md) — capitalization, nested sums, number conversion, and string collection.
5. [Level 5: backtracking](./level5-Leetcode/MediumProblems.md) — Combination Sum and Permutations.

Open each problem set and implement the linked TypeScript starters. Existing `solutions.ts` files in levels 1–4 contain reference work; save them for review after attempting the exercises.

For every exercise, identify the base case and recursive step, then explain time and call-stack space complexity. Check the examples and boundary cases in the problem set. Keep inputs and outputs within JavaScript’s safe integer range, and start with small inputs when tracing recursion.
